# Secretary Bot website

The home page, privacy policy and terms of service for **Secretary Bot**, a
personal student project: a Discord bot that sends a daily plan from Canvas and
Google calendars. Google requires an app's sign-in screen to link to pages like
these, so they're published here with GitHub Pages:

- Home: https://landautzou.github.io/secretary-bot/
- Privacy policy: https://landautzou.github.io/secretary-bot/privacy.html
- Terms of service: https://landautzou.github.io/secretary-bot/terms.html

This repository holds only these pages: plain HTML and one stylesheet, with no
build step. The bot's code is in a separate, private repository.

## Updating the pages

The pages come from the `site/` folder of the bot's repository. After changing
them there, upload the changed files here (**Add file → Upload files**), and
GitHub Pages republishes the site within a few minutes. Whenever what the
privacy policy says changes, update its "Last updated" date too.
